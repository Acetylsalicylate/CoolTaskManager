# Cool Task Manager

Лёгкий диспетчер задач для Windows, сделанный с C++23, Dear ImGui, GLFW, и OpenGL.

## Возможности

* **Вкладка процессов:**
  * Отображает список запущенных процессов, рядом с именем — иконка исполняемого файла.
  * Отслеживает **PID**, **PPID**, владельца (**пользователя**), **сессию**, **нагрузку CPU**, **ОЗУ**, число **потоков** и **дескрипторов**, **приоритет** и **путь** к .exe.
  * При наведении на имя процесса показываются время запуска, суммарное процессорное время и подробные счётчики памяти (рабочий набор, приватные байты, файл подкачки).
  * **Open** в столбце Path открывает папку с выделением исполняемого файла в Проводнике.
  * **Group: PPID** переключает плоский список и дерево «родитель → дочерние» по идентификаторам родительских процессов; строка-группа показывает суммарные CPU, ОЗУ, потоки и дескрипторы всей ветки.
  * Поле поиска над таблицей фильтрует по имени исполняемого файла, PID или PPID; строка под курсором подсвечивается.
  * Клик по строке выбирает процесс. **End task** завершает выбранный процесс после подтверждения, **New task** открывает окно «Create task» и запускает введённую командную строку.
  * Сортировка по клику на заголовок столбца (порядок применяется и внутри каждой группы); ширина столбцов подстраивается под содержимое и их можно растягивать.
  * Обновление данных по кнопке или опциональное авто-обновление раз в секунду.
  * Если Windows запустила приложение с низкой целостностью (из «песочницы»), управление Проводником блокируется: в панели появляется предупреждение и кнопка **Restart as administrator**. Запуск от администратора заодно открывает детали защищённых системных процессов.
* **Вкладка аппаратного обеспечения(АО):**
  * Слева — список комплектующих по отдельности: компьютер, ОС, материнская плата, каждый ЦПУ, ОЗУ с модулями, каждый диск и его тома, каждая ГПУ, каждый сетевой адаптер, батарея.
  * Справа — всё, что hwinfo знает о выбранном компоненте: производитель, модель, серийные номера, прошивка, кеши, модули памяти, PCI ID, версии драйверов, скорости линков.
  * **ЦПУ:** средняя нагрузка, нагрузка по потокам, частоты, график нагрузки и история нагрузки по потокам.
  * **ОЗУ:** занято и доступно, с графиком использования.
  * **Диски:** свободное место и вместимость каждого тома с полосой заполнения.
  * **ГПУ:** нагрузка, память, температура, потребление, вентилятор, частоты, PCIe-линк и графики нагрузки, памяти и температуры.
  * **Сеть:** скорость линка и приём/передача, снимаемые через WinAPI (`GetIfEntry2`) и отображаемые графиками.
  * Данные об аппаратном обеспечении собираются в фоновом потоке, поэтому окно остается отзывчивым во время опроса системы.
* **UI:** Элегантный графический интерфейс в тёмных тонах, созданный на базе Dear ImGui.

## Технический Стек & Зависимости

* **Язык:** C++23 (для современных функций по типу `std::format`, `std::chrono` and `std::expected`)
* **GUI фреймворк:** [Dear ImGui](https://github.com/ocornut/imgui) (v1.90.4, fetched by CMake)
* **Рендер:** [GLFW](https://github.com/glfw/glfw) & OpenGL
* **Информация об АО:** [hwinfo](https://github.com/lfreist/hwinfo) библиотека
* **API:** Windows API (`tlhelp32.h`, `windows.h`) для отслеживания процессов

## Системные Требования

* **ОС:** Windows (Ввиду WinAPI)
* **Компилятор:** C++23 совместимый компилятор (MSVC с Visual Studio 2022 или новее)
* **Сборка:** CMake 3.22 или новее
* **Сеть:** первый запуск клонирует Dear ImGui; далее сборка проходит оффлайн.

## Сборка и запуск

1. Клонируйте репозиторий и подмодули:

   ```bash
   git clone --recursive https://github.com/Acetylsalicylate/CoolTaskManager.git
   cd CoolTaskManager
   ```

   Для уже существующего клона получите подмодули с помощью:

   ```bash
   git submodule update --init --recursive
   ```

2. Настройте и соберите проект:

   ```bash
   cmake -S . -B build
   cmake --build build --config Release
   ```

3. Запустите `build/Release/CoolTaskManager.exe` .

> Библиотека hwinfo подключена как разделяемая библиотека, поэтому файлы `hwinfo_*.dll` должны находиться рядом с исполняемым файлом. CMake уже помещает их в тот же выходной каталог, где располагается приложение.

### Иконка приложения

Иконка окна, панели задач и проводника берётся из `icon.ico` и встраивается в исполняемый файл скриптом ресурсов `CoolTaskManager.rc`; CMake компилирует его компилятором ресурсов из Windows SDK (`enable_language(RC)`). Один и тот же файл хранится под двумя именами: `IDI_APP` — иконка исполняемого файла и `GLFW_ICON` — иконка класса окна, которую загружает GLFW. Чтобы сменить иконку, достаточно заменить `icon.ico` и пересобрать проект — больше ничего править не нужно. Имя файла `.rc` оставляйте в ASCII: компиляторы ресурсов старше 14.4x не принимают не-ASCII пути.

> Если после пересборки в панели задач осталась старая иконка, открепите приложение: Windows кеширует иконки закреплённых и недавних элементов.
